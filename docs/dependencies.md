# Dependency stack

`pnpm-workspace.yaml` owns the catalog, overrides, install permissions, release-age exceptions and patches. Move each related entry together. Workspace manifests select `catalog:` entries; `pnpm-lock.yaml` is generated by pnpm. The root pins pnpm 12.15.0 and Node 26.12.1. Do not use a second lockfile or replace the compiler alias with Microsoft's TypeScript package.

## Constraints requiring reconciliation

- Material Color Utilities 0.4.0 has missing `.js` extensions in its published scheme and dynamic-color ESM imports. The patch adds those extensions for standards-compliant loaders. Its exact override and patchedDependencies entry move together; remove the patch when the upstream package supplies those imports correctly.
- Lucide and lucide-react remain exact 0.564.0 together. Version 1.61.0 removes 57 previously resolvable saved project-icon names (including brand icons). Move this pair only with a proven compatibility path for persisted icon names; do not silently replace saved icons with the fallback.
- TanStack React Router 1.170.10 and router-plugin 1.168.13 remain paired. New React Router 1.170.46 ignores client navigation in server mode; enabling client mode in the existing Node memory-router tests requires `window`. Migrate those navigation cases to the required browser harness before moving this pair; do not fake a DOM or loosen the repository's ban on DOM unit-test environments.
- Expo UI 58.0.23, Legend List 3.6.0 and keyboard-controller 1.22.8 reject existing patch hunks. Their toolbar/color, virtualized-list and keyboard-inset behavior must be reconciled before moving the native set. Other Expo 58 updates remain with that set. PDF JSI 6 introduces a Nitro native dependency and is not a manifest-only replacement for patched 5.
- Alchemy beta.84 no longer has the patched Drizzle/Postgres files and changes its test adapter. Keep beta.80 / Distilled rc.13 until those integrations have equivalents and relay tests prove them.
- Noble 2 uses `.js` subpaths, fixed 32-byte P-256 private scalars, `isValidSecretKey` and byte-returning signatures. Shared DPoP, mobile key generation and APNs JWT signing must move together with explicit `prehash: false` and compact signatures. The jsdom dependency's optional-peer override follows the hashes catalog too, so it cannot split Vite+/Vitest into two instances.
- Babel 8 is outside the Babel 7 peer range of Expo 58's installed transform plugins. Move the preset and plugins together before changing the compiler major.

Security overrides keep proxy-addr 2, shell-quote 1, Hono 4, ip-address 10, body-parser 2, fast-uri 3, Sharp 0.35, Zod 4 and Undici 6/7 on patched releases within their existing major. D-Bus uses xml2js 0.6.2, Xcode project generation uses UUID 11.1.1, and KaTeX is shared at 0.19.1. Remove each override when every parent resolves its fix without it. Zod 3 in Expo tooling and node-forge 1.4.0 remain audit gaps: there is no patched release in those retained lines; do not force Zod 4 into a Zod 3 consumer.

## Updating and verification

Use `pnpm -r outdated --format json`, edit the catalog/manifests and every associated override, patch and release-age exception, then `pnpm install` and `pnpm install --frozen-lockfile`. Check `pnpm peers check`; existing mobile peer exceptions are not proof of compatibility for a new package. Refresh patches against the published package rather than relying on patch fuzz. Do not approve dependency-shipped agent skills; our skills are curated.

Run `vp run check:changed` and focused provider/editor/crypto or packaging tests for moved seams. The check includes format, both Knip passes, affected typechecks and an unused-patch resolution. The SlipJay runner owns assembled landing verification; do not run full repository test/typecheck suites locally. Native changes additionally require their actual platform build and smoke checks. Do not claim hardware, live-provider or installed-app evidence from unit tests.

`.repos` contains read-only library references; use `vp run sync:repos --repo effect-smol` (or `alchemy-effect`) when moving its library. That command uses Git subtree and must run in an isolated checkout with compatible Git metadata; never run it against the primary checkout to work around workspace tooling.
